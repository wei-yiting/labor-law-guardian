## Artifacts & Documentation Language Policy

- **Primary Language:** All generated artifacts (including but not limited to Tasks, Implementation Plans, Technical Walkthroughs, and Comments) **MUST** be written in **Traditional Chinese (zh-TW)**.
- **Terminology Preservation:** Keep technical terms, concepts, and industry standards in their original **English** form.
  - _Example:_ Use "RAG", "Vector Database", "Embedding", "Middleware", "Asynchronous" instead of their Chinese translations.
- **Code Syntax:** All code snippets, variable names, function names, and file paths must remain in **English**.
- **Tone:** Professional, concise, and developer-oriented.
